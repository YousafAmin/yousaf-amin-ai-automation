# ZARÉVA — Wordmark Study

Three luxury serif wordmark directions for ZARÉVA, an affordable-luxury artificial
jewelry brand sold on Shopify/COD in Pakistan. Each direction ships the same six
formats so it can be dropped into packaging, Shopify, Instagram, and print without
redrawing anything.

Full comparison with rationale for each direction:
https://claude.ai/code/artifact/15bc00dc-3230-4017-ab83-b57e78fbf421

## Directions

| Folder | Name | Typeface | Accent |
|---|---|---|---|
| `v1-cormorant/` | Quiet Ivory | Cormorant Garamond, weight 500, 0.34em tracking | Muted gold on the É only |
| `v2-playfair/` | The Editorial Line | Playfair Display, weight 600, 0.20em tracking | None — ink only |
| `v3-prata/` | Deco Facet | Prata, weight 400, 0.30em tracking | Muted gold on the É and a double hairline rule |

## Files (per direction folder)

- `01-horizontal-wordmark.png` — main lockup, ivory background. Headers, banners, packaging tape.
- `02-compact.png` — square lockup (Z icon + wordmark). Instagram avatar, packaging sticker.
- `03-black-on-white.png` — thank-you cards, invoices.
- `04-white-on-black.png` — jewelry box, ribbon foil.
- `05-transparent.png` — alpha-channel PNG for product photography overlays.
- `06-icon-favicon.png` — Z monogram in the direction's signature frame. Favicon, app tile, wax-seal sticker.

All PNGs are rendered at 3x scale (horizontal wordmarks are 7200×2400px) so they hold up
at both business-card and banner size.

Palette: ink black, warm ivory, and — only where noted above — a single muted gold used
as a line or a lone accented letter, never a gradient.
